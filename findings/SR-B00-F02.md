# SR-B00-F02 — Repeated HTML element identifiers across canonical pages

Workstream: Phase 00 / A06 and A14. Observation: 2026-11-27 14:08 IST. Proposed severity: Medium (raise if functional or accessibility impact confirmed). Evidence status: verified source-level counts; DOM scope and affected controls pending. Review status: Open.

## Evidence and methodology
31 of 31 distinct self-canonical pages have a nonzero duplicate_id_count. Sixteen pages have 5 excess ID occurrences each, fifteen have 7 each, total 185. Homepage, contact, intermediate, integrated JEE and NEET each have 7; about, MPC, BiPC, blog and gallery each have 5. Excludes redirects and /Sports/ alias.
Collector code computes sum(v-1 for v in p.ids.values() if v>1) for nonempty ID attributes. This is excess occurrences beyond the first instance of each ID per response, not the number of distinct duplicated ID strings. Original JSON SHA-256 f1ce16437a0a19dc260d0859814c17716f7f29673c74e36378cbf5f1ad0a137a. Exact IDs and element contexts were not retained. The parser does not distinguish separate tree scopes (e.g. template content). Shared template cause is a hypothesis.
Standard: https://html.spec.whatwg.org/multipage/dom.html#the-id-attribute — IDs must be unique within the element's tree.

## Potential impact
Repeated IDs within the same document tree can cause ambiguous fragment navigation, script element selection, label associations and ARIA references. No form malfunction, accessibility failure, ranking loss or security vulnerability has been demonstrated.

## Reproduction
Open homepage and representative admissions pages in Chrome. In the developer console, run:
```js
const counts = new Map();
for (const el of document.querySelectorAll('[id]')) {
  if (el.id) counts.set(el.id, (counts.get(el.id) || 0) + 1);
}
console.table([...counts].filter(([, n]) => n > 1).map(([id, count]) => ({id, count})));
```
This is read-only and measures the live document DOM, not the original source. Compare with source HTML validator and inspect scope, affected elements and references; no form submission.
