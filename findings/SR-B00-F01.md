# SR-B00-F01 — No native H1 heading across all 31 canonical pages

Workstream: Phase 00 / A07 on-page SEO and A14 accessibility. Date: 2026-11-27 14:08 IST. Priority: High (proposed). Evidence status: verified in collected raw source metrics. Review status: Open.

All 31 are listed in page-sitemap.xml. Homepage: H1=0, H2=19, H3=18, H5=2. About: H1=0, H2=15; contact: H1=0, H2=19; integrated JEE and NEET pages: H1=0, H2=12 each.

## Reproduction
Open https://sriraama.in/ and use View Page Source, or fetch HTML with curl. Inspect actual H1 element tags (not CSS references). Repeat on https://sriraama.in/about-us/ and the integrated JEE and NEET pages. Compare to rendered DOM, accessibility tree and full crawl export. Browser capture not yet collected.

## Assessment
Consistent lack of a native top-level heading in source is a semantic content hierarchy quality gap across the site. It is not proof of a Google ranking penalty, non-indexability, a WCAG failure by itself, or AI crawler exclusion. Equivalent ARIA headings and rendered DOM are not tested. High audit priority reflects systemic scope and core admissions pages.
